## 👋 Sobre mim

Sou estudante do **último ano do curso técnico em Desenvolvimento de Sistemas no SENAI**. Venho desenvolvendo projetos acadêmicos e pessoais para praticar programação, modelagem de dados e construção de interfaces.

Tenho interesse especial em **Flutter/Dart, Back-End e banco de dados**. Gosto de entender o caminho completo de uma aplicação — da organização dos dados e das regras de negócio até a interface com a qual a pessoa interage.

Meu GitHub reúne exercícios de formação, experimentos e projetos em evolução. Procuro deixar claro o que está concluído, o que continua em desenvolvimento e quais conhecimentos cada projeto me permite praticar.

## 🧭 No que estou focado

- **Mobile:** desenvolvimento de interfaces e navegação com Flutter e Dart.
- **Back-End e dados:** PHP, Node.js, SQL e integração com bancos de dados.
- **Evolução dos projetos:** melhorar organização, documentação e qualidade do código.
- **Objetivo profissional:** conquistar uma oportunidade de estágio ou primeira experiência como desenvolvedor.

## 🛠️ Projetos em desenvolvimento e projetos pessoais

### 📱 DevFolio App
**Flutter · Dart · Material Design 3** · Em desenvolvimento

Aplicativo de portfólio profissional criado como projeto final de PPDM. A proposta inclui telas de Perfil e Dashboard, componentes reutilizáveis e adaptação do layout para diferentes larguras de tela.

**Conceitos praticados:** `LayoutBuilder`, navegação adaptável, `GridView`, `Wrap`, `Stack`, `Card` e organização visual com Material Design 3.

> O projeto ainda contém conteúdo demonstrativo e não possui um repositório público confirmado neste perfil.

### 🤖 JARVIS BR-01
**Python · Flutter/Dart** · Em desenvolvimento

Projeto pessoal de assistente para Windows, inspirado em assistentes de ficção científica. A ideia é organizar os componentes em módulos independentes para facilitar a evolução do sistema.

**Direção do projeto:** comandos por voz, palavra de ativação e automação do computador. Recursos como visão computacional e análise de tela devem ser tratados como objetivos futuros até estarem efetivamente implementados.

> O projeto ainda não possui um repositório público confirmado neste perfil.

### ⚽ Simulador da Fase de Grupos — Copa 2026
**Dart puro · CLI** · Concluído

Simulador de uma fase de grupos executado pelo terminal. Registra resultados e monta uma classificação aplicando regras de desempate implementadas no projeto.

**Conceitos praticados:** classes, `enum`, ordenação personalizada com `.sort()`, carregamento assíncrono e tratamento de erros com `try/catch`.

> Projeto concluído, mas o repositório ainda não está publicado neste perfil.

**MPDWorks — Sua Casa Sempre** · Em andamento

Projeto acadêmico de um sistema relacionado a serviços de manutenção residencial. O trabalho passou por etapas de Back-End e modelagem de dados, além de uma interface web baseada em uma proposta visual feita no Figma.
